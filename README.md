# 火山今天请假 · 立体绘本

一本会动的黏土立体书：封面加 5 个跨页、12 个镜头。拖动书页翻页，在书外空白处拖动可以绕中心轴转动，滚轮缩放；小火山噗噗和小鸟按分镜在书页上表演、对话，底部进度条显示每页的表演进度。

在线阅读：https://chatyu12.github.io/volcano-day-off-popup-book/ （网址后加 `#p1`–`#p5` 可直达某页）

- `index.html`：three.js 立体书页面
- `manifest.js`：从资产包 `导入清单.json` 抽出的贴图尺寸、可见边界和定位点（折轴、火山口、鸟嘴、树枝、挂孔等）
- `WebP/`：资产包里的 62 张网页贴图
- `vo/`：旁白、噗噗、小鸟的配音（Kokoro-82M v1.0 中文音色，Apache 2.0），`vo/vo.json` 是台词到音频的对照表
- `tools/`：从 `index.html` 抽取台词并生成配音的脚本
- `PROMPT.md`：合并优化后的最终提示词（剧本、分镜节拍、布景、技术要求、配音、补图前缀）
